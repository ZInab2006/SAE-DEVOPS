Web Application Basics

🧭 Contexte

Cette room pose les bases du fonctionnement d’une application web. Elle montre ce qui se passe entre le navigateur et le serveur : requêtes, réponses, sessions, authentification… soit l’essentiel de ce qu’on manipule au quotidien sans toujours en avoir conscience.

Elle ne se limite pas à la théorie : on apprend aussi à repérer les zones sensibles d’un site (formulaires, cookies, gestion des sessions, etc.), là où les failles les plus courantes apparaissent. C’est une bonne introduction avant les rooms OWASP plus techniques.

💭 Points clés

Souvent, un site est perçu comme un ensemble de pages. Ici, l’accent est mis sur les échanges entre le client et le serveur : c’est ce qui permet d’analyser correctement le comportement d’une application.

On comprend que beaucoup de failles viennent de petites erreurs qu’on commet sans s’en rendre compte :

  • entrées utilisateur mal filtrées ;
  • mauvaise gestion des sessions ou des cookies ;
  • contrôles faibles ou absents côté serveur.

La room encourage des réflexes concrets : valider les données, sécuriser les connexions (HTTPS), appliquer les droits au bon niveau, et garder des logs exploitables pour comprendre un incident. Ces principes se réutilisent directement dans un projet comme la SAE.

✨ En bref

En synthèse, cette room constitue une base solide avant le reste du parcours OWASP. Elle rappelle que la sécurité ne se « rajoute » pas à la fin : elle se construit dès le départ, avec des choix simples et des vérifications régulières.

Pour comprendre les bases du web et limiter les erreurs les plus exploitées, le contenu reste clair, accessible, et utile pour la suite du parcours.
