Windows Command Line

TryHackMe, Parcours Cyber Security 101 (Partie I)

Contexte

Cette room porte sur la ligne de commande Windows : commandes de base pour interagir avec le système sans passer par l’interface graphique. On y voit comment obtenir des informations système, vérifier la configuration réseau, gérer les processus, parcourir les répertoires et manipuler des fichiers depuis l’invite de commandes.

Points clés

La ligne de commande est un outil central pour l’administration et le dépannage. Des commandes comme systeminfo, ipconfig ou tasklist donnent rapidement des informations précises sur le système, le réseau et les processus — souvent de façon plus directe que via l’interface graphique.

Pour le réseau, ping, tracert, nslookup et netstat aident à comprendre la connectivité, repérer des problèmes de communication et observer les connexions actives.

Pour les fichiers et dossiers : cd, dir, mkdir, copy, move, del. La gestion des processus (taskkill) et des arrêts (shutdown) montre l’ampleur du contrôle possible en ligne de commande.
