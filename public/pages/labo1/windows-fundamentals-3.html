Contexte

Ce volet met l'accent sur les traces laissees par le systeme : journaux, evenements et outils d'observation. Ces elements sont essentiels pour comprendre un incident et reconstruire une chronologie.

Ce que nous avons compris

Nous avons compris qu'un poste Windows fournit de nombreuses informations utiles a la detection si les logs sont bien collectes. L'approche combine interface graphique et commandes pour obtenir une vision complete.
