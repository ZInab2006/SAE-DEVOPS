Offensive Security Intro

TryHackMe — Parcours Cyber Security 101 (Partie I)

Contexte

Cette room explique la logique de la securite offensive : tester un systeme de maniere autorisee pour identifier les failles avant un attaquant reel. L'objectif est d'apprendre une methode, avec un cadre legal clair, puis de documenter les points a corriger.

Ce que nous avons compris

Nous avons retenu qu'une approche offensive n'est utile que si elle debouche sur des corrections concretes. La reconnaissance, l'identification de surface d'attaque et la validation technique servent surtout a prioriser la remediation.

Conclusion

Cette room pose une base utile pour la suite : comprendre une attaque dans un environnement d'apprentissage, puis traduire les resultats en actions defensives.
