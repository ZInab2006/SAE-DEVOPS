Windows Fundamentals 1

TryHackMe — Parcours Cyber Security 101 (Partie I)

Contexte

Cette première room Windows m'a permis de revoir les bases du système dans un contexte cybersécurité. On y traite la structure de Windows, les comptes utilisateurs, les privilèges, le système de fichiers NTFS et les outils d'administration principaux.

Ce que nous avons compris

J'ai compris que connaître juste l'interface graphique ne suffit pas pour sécuriser un poste. Il faut aussi comprendre les droits utilisateurs, les groupes, les dossiers système et les permissions NTFS pour identifier les risques. Cette room m'a aidée à mieux lire l'environnement Windows avant d'aller vers des analyses plus avancées.

Conclusion

Ce premier volet m'a donné une base claire sur Windows. Je suis maintenant plus à l'aise pour passer aux mécanismes internes et à la détection dans les parties suivantes.
