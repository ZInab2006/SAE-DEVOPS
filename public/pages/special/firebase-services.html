Services Firebase Utilisés

Contexte

Cette page présente les services Firebase choisis pour la SAE avec une explication courte de leur rôle. Le service obligatoire est Firebase Hosting, utilisé pour publier le site en ligne.

Ce que nous avons mis en place

  • Firebase Hosting : hébergement du site statique avec point d’entrée unique et routage client.
  • Configuration : fichiers .firebaserc et firebase.json pour lier le projet et définir la publication.
  • Déploiement : publication via CLI Firebase avec suivi des versions GitHub.

Synthèse

Firebase Hosting répond bien au besoin du projet : déploiement rapide, accès web simple et intégration facile avec notre flux Git.
