Services Firebase Utilises

Contexte

Cette page presente les services Firebase choisis pour la SAE avec une explication courte de leur role. Le service obligatoire est Firebase Hosting, utilise pour publier le site en ligne.

Ce que nous avons mis en place

  • Firebase Hosting : hebergement du site statique avec point d'entree unique et routage client.
  • Configuration : fichiers .firebaserc et firebase.json pour lier le projet et definir la publication.
  • Deploiement : publication via CLI Firebase avec suivi des versions GitHub.

Synthese

Firebase Hosting repond bien au besoin du projet : deploiement rapide, acces web simple et integration facile avec notre flux Git.
